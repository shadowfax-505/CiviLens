# CivicLens Roadmap

## V1: Enterprise Foundation

- Build Laravel application foundation.
- Implement authentication, roles, agencies, projects, budgets, procurements, suppliers, documents, reports, search, analytics, and audit logging.
- Produce reliable documentation and tests with every sprint.

## V2: Public Intelligence Platform

- Add public open-data APIs.
- Add richer geospatial views.
- Add OCR and document extraction.
- Add explainable risk indicators.
- Add more scalable deployment and observability.

## V3: Civic Intelligence Ecosystem

- Add multi-tenant support.
- Add partner integrations.
- Add advanced analytics and data quality pipelines.
- Add model governance for AI-assisted insights.
