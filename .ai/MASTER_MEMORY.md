# Master Memory

## Project

CivicLens is an AI-assisted Civic Intelligence Platform. V1 is a Laravel data platform for civic projects, agencies, budgets, procurements, suppliers, documents, reports, search, analytics, and audit logs.

## Core Rule

Build v1 as a stable, database-first platform. Store advanced ideas in `docs/v2/` until promoted through an ADR.

## Stack

Laravel, PHP, MySQL, Redis, Laravel Scout, Meilisearch, Tailwind CSS, Livewire, Pest/PHPUnit, Docker or Laravel Sail.
