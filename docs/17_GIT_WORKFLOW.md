# 17 Git Workflow

## Branches

Use focused branches such as `feature/projects-module`, `fix/project-status-validation`, or `docs/database-bible`.

## Commits

Use concise conventional-style messages:

- `feat: add project status history`
- `docs: expand database bible`
- `test: cover project authorization`

## V2 Promotion

Moving a v2 idea into v1 requires an ADR and roadmap update.
