# 20 Open Data Policy

## V1 Policy

V1 prepares structured data but does not automatically publish every record.

Sprint 11 adds public web views for approved records only. This is not an open-data export program: dataset versioning, public API contracts, license payloads, and bulk downloads remain v2 scope.

## V2 Policy

Public datasets should include license, schema version, generated timestamp, and excluded sensitive fields.
