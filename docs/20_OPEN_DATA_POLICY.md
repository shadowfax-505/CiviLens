# 20 Open Data Policy

## V1 Policy

V1 prepares structured data but does not automatically publish every record.

Sprint 11 adds public web views for approved records only. This is not an open-data export program: dataset versioning, public API contracts, license payloads, and bulk downloads remain v2 scope.

## V2 Policy

Public datasets should include publisher, source class, original URL, license or rights status, schema version, generated timestamp, geographic scope, review state, and excluded sensitive fields. Public timelines may mix government and non-governmental items only when the source class is explicit.

CivicLens links to the publisher's original resource and publishes only a short reviewer-approved source-attributed summary unless separate rights permit republication. Removal, correction, supersession, and **under re-review** states remain visible in version history.
