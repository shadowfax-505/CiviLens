# ADR-006: Keep V2 Ideas Separate from V1 Implementation

## Status

Accepted

## Context

The research report includes advanced AI, public API, semantic search, and scalability ideas that can overwhelm v1.

## Decision

Store future capabilities in `docs/v2/` until promoted through ADR.

## Consequences

V1 remains buildable while v2 stays visible and planned.

## V2 Impact

This decision directly enables a clean transition to v2.
