# 16 Coding Standards

## PHP and Laravel

- Follow PSR standards.
- Use Laravel Pint.
- Prefer form requests for validation.
- Use policies for authorization.
- Keep controllers thin.
- Put business rules in services or actions when they grow.

## SQL

- Use explicit foreign keys.
- Index common filters.
- Avoid storing derived facts as source truth.

## Documentation

Update docs in the same change as code.
