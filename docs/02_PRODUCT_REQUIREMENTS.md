# 02 Product Requirements

## Functional Requirements

- Users can register, log in, and manage profile basics.
- Administrators can manage roles and permissions.
- Staff can create agencies, locations, projects, budgets, procurements, suppliers, contracts, documents, and reports.
- Citizens can browse public project information and submit reports when enabled.
- Users can search projects and documents.
- Administrators can view analytics and audit logs.

## Non-Functional Requirements

- Secure authentication and authorization.
- Normalized database schema.
- Indexed queries for core filters.
- Responsive UI.
- Test coverage for critical flows.
- Documentation updated with each feature.

## V2 Expansion Notes

V2 requirements should add OCR, public datasets, map views, semantic search, and explainable risk indicators.
