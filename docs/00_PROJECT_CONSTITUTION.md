# 00 Project Constitution

This constitution is the highest-level authority for CivicLens.

## Mission

CivicLens exists to improve transparency, accountability, and evidence-based civic decision-making through well-structured public-sector data.

## Core Principles

- Data first: the database is the foundation.
- Explainable intelligence: AI outputs must show supporting evidence.
- Security by default: protect accounts, documents, and audit trails.
- Documentation as code: decisions live in the repository.
- Versioned evolution: v1 decisions must leave a clear path to v2.

## Non-Goals

- CivicLens does not make legal accusations.
- CivicLens does not replace human review.
- CivicLens v1 does not require advanced AI before the data platform is reliable.

## Definition of Done

- Feature implemented.
- Tests added.
- Documentation updated.
- Security impact reviewed.
- V2 impact recorded when relevant.
